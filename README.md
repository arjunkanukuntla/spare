# SPARE — Hyperlocal Surplus Redistribution Platform

> **Tagline:** Someone can use what you don't.  
> **Supporting message:** Less waste. More use.

SPARE is a hyperlocal surplus redistribution platform designed to connect people, businesses, and organizations who have unneeded surplus (food, books, calculators, electronics, clothes, furniture, household goods) with nearby individuals and NGOs who can use them.

Primary transactions on SPARE are **FREE (₹0)** with optional convenience delivery fees.

---

## 🌟 Key Features

- **Hyperlocal Feed & Search:** Browse free listings, expiring time-sensitive food surplus, and nearby community requests.
- **Smart Matching Matrix:** Deterministic allocation algorithm calculating distance radius, urgency, category, and organization capacity to distribute large surplus (e.g. 220 wedding meals across shelter NGOs, hostels, and individuals).
- **Quick Auto-Fill Helper:** Auto-detects item category, title, condition, and description from uploaded images.
- **Food Safety & Hygiene:** Mandatory provider declarations, preparation timestamps, veg/non-veg tags, and thermal/packaging status tracking.
- **Partial Claims & OTP Verification:** Claim custom quantities with 4-digit pickup OTP codes verified by providers.
- **Event Surplus Calculator:** Instant tool for weddings, caterers, and events to calculate unconsumed meals (`Expected − Attended = Surplus`) and list in 1 click.
- **Interactive Explore Map:** Visual hyperlocal map showing pins within walking/pickup distance with location privacy protection.
- **Business & Organization Dashboards:** Track prepared vs sold vs surplus metrics, ESG zero-waste ratings, and NGO bulk claims.
- **Impact Telemetry:** Real-time platform impact stats tracking meals redistributed, items reused, financial value rescued (₹), and claim velocity.

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
